# Privacy Policy

NitSig does not store or collect any personal information. All user preferences for the use of the extension are stored on the user's device in local storage. The extension does not collect any information about the user's browsing activity or the content they are viewing.

The web extension requires the following permissions with the following reasons:

-   Access to the user's local storage
    -   This permission is required to store user preferences for the use of the extension.
-   Access to the user's browsing activity with the domain "sigarra.up.pt"
    -   This permission is required to detect when the user is on page to improve the user experience.
-   Access to the user's cookies
    -   This permission is used for the "logged in" option to automatically log the user in to the website by storing the user credentials.

This privacy policy can be updated at any time without prior notice. If you have any questions or concerns regarding this privacy policy, please contact us at ni@aefeup.pt.
